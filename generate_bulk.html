JSON Configuration Format

Sequence format: frequency, duration, rampDuration, rampType, carrierFreq
Fields 3-5 are optional. rampType: 0=linear (default), 1=exponential. carrierFreq: Solfeggio frequency for this step.

Generation Rules:

  • When backgroundSound is "white", "pink", or "brown": the noise is rendered with the slow 2–15 kHz lowpass sweep (8-minute cycle)
  • When backgroundSound is an audio file: the file is looped for the session length and the pre-flight analysis reports how it interacts with the session's carriers
  • Either way the background is normalised to the Background Sound Volume (active RMS), limited, and gets the carrier dip; every other setting comes from the fields above
